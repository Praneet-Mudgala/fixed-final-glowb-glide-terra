# Glowb's Glide
For Hack Club Terra!

Glowb's Glide is a fast paced infinite sidescroller where you control a dumbo octopus named GlowB as he runs across the ocean floor. Watch out for sea urchins and pufferfish that may hurt you. Survive for as long as possible and increase your score! It gets harder as you go. Try and beat your highscore as well.

## Instructions
* In order to play, go to this link: https://praneet-mudgala.github.io/fixed-final-glowb-glide-terra/
* Once you're in, press space to start.
* Press space to jump and run for as long as possible!
* Don't worry if you die, you can always restart.

## Technical Details
This project was build using Godot 4 and GDScript. I've built an infinite scrolling background that spawns enemies and gets harder as your score increases.
